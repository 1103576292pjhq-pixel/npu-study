# 任务07：数字电路基础

## 本章知识全景图

### 1. 一眼看懂这讲在讲什么

数字前端虽然主要写 RTL，但 RTL 最终不是停在代码里，而是被综合成标准单元，再落到 CMOS 晶体管网络。本讲的主线是从 MOS 管的受控导通出发，建立 CMOS 反相器、VTC、功耗、标准单元、NAND/NOR 的底层直觉。学完后，你应该能把一句 `assign y = ~(a & b);` 连接到真实的上拉/下拉网络、负载电容充放电和功耗来源。

核心概念：MOS、PMOS、NMOS、CMOS 反相器、负载电容、VTC、噪声容限、动态功耗、短路功耗、漏电功耗、FinFET、standard cell、NAND、NOR。

逻辑主线：

- MOS 管先按“由栅极控制的开关”理解。
- CMOS 反相器用 PMOS 上拉、NMOS 下拉实现取反。
- 输出电平变化不是抽象赋值，而是负载电容充放电。
- VTC 说明 0/1 是电压范围，不是两个理想点。
- 功耗来自翻转充放电、上下管短暂同时导通和关断漏电。
- 标准单元把门电路版图化，综合工具把 RTL 映射到这些单元。
- NAND/NOR 的晶体管结构来自上拉/下拉网络的互补关系。

### 2. 概念地图

| 层级 | 概念 | 一句话定义 | 后续工程用途 |
|---|---|---|---|
| 器件 | NMOS / PMOS | 栅极控制源漏通路的开关 | 理解门电路、延迟和功耗 |
| 基本门 | CMOS 反相器 | PMOS 上拉 + NMOS 下拉 | 建立标准单元直觉 |
| 电气行为 | VTC / 噪声容限 | 输入电压到输出电压的转换关系 | 判断电平识别可靠性 |
| 能量行为 | 动态/短路/漏电功耗 | 翻转、过渡、关断仍耗能 | 低功耗设计和功耗报告阅读 |
| 逻辑门 | NAND / NOR | 上拉/下拉网络组合 | 理解综合后的门级结构 |
| 工艺库 | standard cell | 预先设计好的门级版图单元 | DC 综合、STA、面积功耗时序分析 |

### 3. 最短学习路径

1. 用开关模型理解 NMOS 和 PMOS 的导通条件。
2. 用真值表推导 CMOS 反相器为什么输出取反。
3. 把输出节点看成负载电容，理解延迟和动态功耗。
4. 用 VTC 理解输入输出不是理想跳变。
5. 分清动态功耗、短路功耗、漏电功耗。
6. 用 NAND/NOR 练习把逻辑关系翻译成串并联晶体管网络。

本讲可以先用“受控水阀”建立直觉：NMOS/PMOS 像由输入电压控制的阀门，上拉网络把输出接到水塔 `VDD`，下拉网络把输出接到排水口 `GND`，负载电容像水桶，需要时间充满或放空。这个比喻只服务第一层理解，真实晶体管还有阈值、电阻、电容和工艺效应，不能把它想成理想机械开关。

## 1. MOS 管先按“受控开关”理解

MOS 管有源极、漏极、栅极和衬底；对数字电路入门来说，第一层模型可以先压成“栅极控制源漏之间是否导通”。这个模型不解释全部物理细节，但足够支撑后续门电路直觉。

视觉验证：04:00-07:00，画面展示 MOS 管结构和栅极控制通道的基本图示。

![MOS 管结构](<./screenshots/任务007_数字电路基础/01_cmos_inverter_07m05s.jpg>)

这张图要看左侧 PMOS/NMOS 的上下位置和右侧 standard cell 版图轮廓：同一个逻辑门既有电路符号，也会落成有电源轨、扩散区、接触孔和金属连线的物理单元。

最小规则：

- NMOS：栅极为高电平时更容易导通，适合作为下拉网络，把输出节点拉向 `GND`。
- PMOS：栅极为低电平时更容易导通，适合作为上拉网络，把输出节点拉向 `VDD`。
- 导通不是“输出一个 0 或 1”，而是形成一条电气通路。

常见误解是把门级逻辑当成纯符号运算。真正的硬件里，`0` / `1` 对应的是电压区间；门电路只是通过晶体管通断，把输出节点接向电源或地。

## 2. CMOS 反相器：互补开关实现取反

CMOS 反相器由上方 PMOS 和下方 NMOS 组成。输入为低时，PMOS 导通、NMOS 关断，输出节点通过 PMOS 接到 `VDD`，得到高电平；输入为高时，PMOS 关断、NMOS 导通，输出节点通过 NMOS 接到 `GND`，得到低电平。

视觉验证：07:05-16:22，画面展示 CMOS 反相器原理图、版图和一阶 DC 分析。

![CMOS 反相器](<./screenshots/任务007_数字电路基础/01_cmos_inverter_07m05s_2.jpg>)

![CMOS 一阶 DC 分析](<./screenshots/任务007_数字电路基础/02_first_order_dc_16m22s.jpg>)

第一张图看互补结构，第二张图看一阶等效开关。`Vin=0` 和 `Vin=VDD` 两种状态不要只背真值表，要沿着输出节点分别找通向 `VDD` 或 `GND` 的路径。

真值表：

| 输入 `Vin` | PMOS | NMOS | 输出 `Vout` |
|---:|---|---|---:|
| 0 | 导通 | 关断 | 1 |
| 1 | 关断 | 导通 | 0 |

这张表要和电路路径一起记：输出高是因为 `VDD -> PMOS -> Vout` 成立；输出低是因为 `Vout -> NMOS -> GND` 成立。数字前端以后看门级网表时，看到 `INVX1`、`NAND2X1` 这类标准单元，要知道它们背后就是类似的互补晶体管网络。

## 3. 输出翻转不是瞬间赋值，而是负载电容充放电

反相器输出节点通常带有负载电容 `C_L`，可能来自后级门输入、电线寄生、电容性负载等。PMOS 导通时，`VDD` 给 `C_L` 充电，输出上升；NMOS 导通时，`C_L` 向 `GND` 放电，输出下降。

视觉验证：18:00-19:30，画面用输出节点和电容解释充放电过程。

![CMOS 瞬态响应](<./screenshots/任务007_数字电路基础/02_first_order_dc_16m22s_2.jpg>)

这张图虽然是 DC 等效开关图，但它能帮助你补出瞬态过程：输出节点旁边接着等效负载，开关切换后不是“值瞬移”，而是电容沿某条通路充电或放电。

这条机制直接解释三个工程现象：

- 延迟：充放电需要时间，门电路不会零延迟翻转。
- 动态功耗：电容每次充放电都消耗能量，翻转越多功耗越高。
- 驱动能力：管子尺寸、负载电容、连线寄生都会影响翻转速度。

所以时序报告里的 cell delay、net delay、load、transition，不是工具凭空给出的数字，而是晶体管和电容行为的抽象结果。

## 4. VTC 和噪声容限：0/1 是范围，不是理想点

VTC 是输入电压与输出电压之间的转换曲线。理想数字逻辑像是输入一过阈值，输出立刻跳变；真实反相器存在过渡区，输入从低到高连续变化时，输出也会经历从高到低的快速转换。

视觉验证：21:15，画面展示 CMOS inverter 的 VTC 曲线和 `VIL`、`VIH`、`VOH`、`VOL`。

![CMOS VTC 曲线](<./screenshots/任务007_数字电路基础/03_vtc_21m15s.jpg>)

这张图要看四个边界量，而不是只看曲线好看。`VIL/VIH` 定义输入怎么被判，`VOL/VOH` 定义输出能保证到什么范围；噪声容限就在这些范围之间。

关键量：

- `VOH`：输出高电平的保证范围。
- `VOL`：输出低电平的保证范围。
- `VIL`：还能被识别为低输入的最高输入电压。
- `VIH`：能被识别为高输入的最低输入电压。

噪声容限的意义是：线路上有扰动时，电路仍能把电压判成正确的 0 或 1。数字前端写 RTL 时很少直接计算 VTC，但在理解时序、低功耗、电压缩放、工艺角和信号完整性时，必须知道数字逻辑的可靠性来自电气范围，而不是符号本身。

## 5. 功耗三来源：动态、短路、漏电不能混成一个词

课程把 CMOS 功耗分成动态功耗、短路功耗和漏电功耗。低功耗设计不是一个单独技巧，而是分别压低翻转、电流直通和关断泄漏。

视觉验证：25:59，画面列出 Dynamic Power、Short Circuit Currents、Leakage Power。

![功耗来源](<./screenshots/任务007_数字电路基础/04_power_types_25m59s.jpg>)

这张图要把三类功耗拆开：动态功耗来自给水桶反复充放水，短路功耗来自切换瞬间上下阀门短暂同时开，漏电功耗来自阀门关了仍有细小渗漏。

| 功耗类型 | 来源 | 典型降低方法 | 前端关联 |
|---|---|---|---|
| 动态功耗 | 负载电容充放电 | 降低翻转率、门控时钟、降低电压、减小负载 | RTL 活动率、时钟使能、数据通路切换 |
| 短路功耗 | 输入翻转时 PMOS/NMOS 短暂同时导通 | 控制输入斜率、减少毛刺、合理门尺寸 | 毛刺、组合逻辑深度、transition |
| 漏电功耗 | 关断晶体管仍有电流 | 多阈值单元、电源门控、工艺选择 | standby 功耗、低功耗约束 |

短路功耗容易和漏电功耗混淆。短路功耗发生在翻转过渡时，上下管短暂形成 `VDD -> GND` 通路；漏电功耗发生在关断状态下，管子没有理想完全关闭。二者都不是负载电容的正常充放电。

## 6. 动态功耗公式：`VDD` 平方项解释为什么降压很有效

动态功耗来自电容充放电。单次 0 到 1 翻转需要给负载电容充电；反复翻转时，平均功耗与负载电容、供电电压平方、频率和翻转活动率相关。

视觉验证：30:22-35:25，画面给出动态功耗推导和翻转活动率说明。

![动态功耗公式](<./screenshots/任务007_数字电路基础/05_dynamic_power_30m22s.jpg>)

![翻转活动率](<./screenshots/任务007_数字电路基础/06_transition_activity_power_35m25s.jpg>)

第一张图看单次充放电的能量来源，第二张图看 `\alpha` 如何把“是不是每拍都翻转”放进平均功耗。NPU 里大量 MAC、SRAM 和总线并行翻转，`\alpha` 往往比单个门公式更有工程意义。

常用表达：

$$
P_{dyn} \approx \alpha C_L V_{DD}^2 f
$$

符号含义：

- `\alpha`：翻转活动率，表示一个周期内发生有效翻转的概率或比例。
- `C_L`：等效负载电容，包括后级输入和连线寄生。
- `V_{DD}`：供电电压，平方项意味着电压对功耗特别敏感。
- `f`：时钟频率或切换频率。

AI/NPU 数据通路通常很宽，乘加阵列、片上 SRAM、总线和互连都有大量节点同时翻转。前端降低动态功耗的直接手段包括时钟门控、数据门控、减少无效翻转、优化状态机和减少不必要的宽位宽传播。

## 7. FinFET：先进工艺改善栅控能力，但前端仍看库模型

FinFET 用三维鳍式沟道和多面栅控制增强对沟道的控制能力，用来缓解平面 MOS 在先进工艺下的短沟道效应。课程提到它，是为了说明工艺演进会改变器件速度、功耗、面积和漏电表现。

视觉验证：44:52，画面展示 FinFET 的三维结构。

![FinFET 结构](<./screenshots/任务007_数字电路基础/07_finfet_44m52s.jpg>)

这张图只看“栅极包住沟道”的三维控制感。前端不手画 FinFET，但要知道先进工艺的速度、漏电和功耗差异最终会反映在库文件和 PVT corner 里。

对数字前端而言，重点不是手工设计 FinFET，而是理解这些变化最终体现在 standard cell library、时序库、功耗库和工艺角里。你写同一段 RTL，在不同工艺库下综合出来的面积、频率、功耗可能完全不同。

## 8. 标准单元：RTL 不是直接变成晶体管，而是先映射到库

工艺厂商或库团队会提供标准单元库，例如反相器、NAND、NOR、触发器、MUX、缓冲器等。这些单元已经完成晶体管级设计、版图、时序功耗表征。综合工具把 RTL 逻辑映射到这些单元，而不是每次从零画晶体管。

工程链路：

```text
RTL 逻辑
  -> 逻辑综合
  -> 标准单元门级网表
  -> 布局布线
  -> 时序/功耗/面积报告
```

这解释了为什么数字前端要理解门电路但不需要每个门都手画版图：你要知道库单元的行为和代价，才能读懂综合报告和时序问题。

## 9. NAND / NOR：下拉网络决定什么时候输出 0

NAND 和 NOR 是理解 CMOS 组合门的最好练习。先看下拉网络：NMOS 导通时输出被拉到 0；再用互补关系设计上拉网络。

视觉验证：49:36，画面展示 NAND 的 CMOS 结构；54:19，画面展示 NOR 的 CMOS 结构。

![NAND CMOS 结构](<./screenshots/任务007_数字电路基础/08_nand_cmos_49m36s.jpg>)

![NOR CMOS 结构](<./screenshots/任务007_数字电路基础/09_nor_cmos_54m19s.jpg>)

这两张图要按同一口径读：先找 NMOS 下拉网络什么时候能把输出拉到 0，再反过来看 PMOS 上拉网络怎样覆盖其余输入组合。这样读，比直接背“串联/并联”更不容易反。

NAND：

- 逻辑：`Y = ~(A & B)`。
- 输出为 0 的条件：`A=1` 且 `B=1`。
- 下拉网络：两个 NMOS 串联，必须同时导通。
- 上拉网络：两个 PMOS 并联，只要一个输入为 0 就能上拉。

NOR：

- 逻辑：`Y = ~(A | B)`。
- 输出为 0 的条件：`A=1` 或 `B=1`。
- 下拉网络：两个 NMOS 并联，任一导通即可下拉。
- 上拉网络：两个 PMOS 串联，必须两个输入都为 0 才上拉。

记忆口径：下拉网络回答“什么时候输出 0”；上拉网络是互补路径，回答“其余情况下如何输出 1”。这个口径比死背 NAND/NOR 结构更稳。

## 10. 最后速记

### 10.1 本章最该记住的结论

- MOS 管先按栅极控制的开关理解，NMOS 适合下拉，PMOS 适合上拉。
- CMOS 反相器用 PMOS/NMOS 互补导通实现输入取反。
- 输出翻转是负载电容充放电，所以会产生延迟和动态功耗。
- 0/1 是电压范围，VTC 和噪声容限决定识别可靠性。
- 动态功耗近似与 `\alpha C_L V_{DD}^2 f` 成正比，电压平方项非常关键。
- NAND/NOR 的晶体管结构来自下拉网络的串并联逻辑和上拉网络互补。

### 10.2 自测题

1. 为什么输入为 0 时 CMOS 反相器输出为 1？  
   答案要点：输入低使 PMOS 导通、NMOS 关断，输出节点通过 PMOS 接到 `VDD`。

2. 动态功耗为什么和翻转率有关？  
   答案要点：只有节点发生 0/1 翻转时才反复充放电；无效翻转越多，电容充放电次数越多。

3. 短路功耗和漏电功耗有什么区别？  
   答案要点：短路功耗来自翻转过渡时上下管短暂同时导通；漏电功耗来自关断器件仍有泄漏电流。

4. NAND 的 NMOS 为什么串联？  
   答案要点：NAND 只有 `A` 和 `B` 同时为 1 时输出 0，下拉路径必须两个 NMOS 都导通，所以串联。

5. 前端工程师为什么要知道 standard cell？  
   答案要点：RTL 综合目标是标准单元库；时序、功耗、面积报告都基于库单元模型。

### 10.3 实践动作

画出二输入 NAND 和 NOR 的下拉 NMOS 网络，并用真值表逐行验证什么时候输出被拉低。再写出对应的 RTL：

```verilog
assign y_nand = ~(a & b);
assign y_nor  = ~(a | b);
```

检查你的图是否满足：RTL 输出为 0 的行，NMOS 下拉网络一定导通；RTL 输出为 1 的行，上拉网络一定能导通。
